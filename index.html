纪念日与倒数

导航分类

个性化

设置首页欢迎语中显示的称呼，仅保存在当前浏览器。

外观

选择看板的配色主题；跟随系统会随设备的日间/夜间设置自动切换。

天气与位置

天气数据来自免费的 Open-Meteo 开放接口，无需注册、无需 API Key。

AI 助手

接入任意 OpenAI 兼容接口（OpenAI、DeepSeek、各类中转站均可）。API Key 仅保存在当前浏览器，对话时会带上看板的实时数据。

连接与账户
